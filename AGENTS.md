# Operating agreement for this CCS repository

Read README, the relevant rule and only related cases. This repository maintains
methodology and templates; it does not operate the projects used as examples.

- Work from the current user task, an exact branch/HEAD and a clean or explicitly
  understood worktree. Preserve unexpected changes and private project material.
- Generalize lessons. Do not copy private code, runtime logs, credentials, network
  addresses, source identities, account billing statements or private links.
- Distinguish observed evidence from a source-supported inference. A successful
  correction does not retroactively prove an unrecorded historical process tree.
- Reuse relevant existing evidence. Run the lightweight docs check and committed
  whitespace check for docs changes; do not introduce heavyweight application CI.
- For a new transferable case, update the case index, relevant rule and CHANGELOG
  in one coherent revision. Preserve limitations and date provider-specific facts.
- Prefer a task branch and one PR for updates. Corrections belong on that PR.
  Exact-head acceptance precedes separately authorized integration/publication.
- Do not create a commit merely to record its own SHA or CI observation.
- Publishing this repository does not authorize edits, deployments, account changes,
  messages, issue creation or monitoring in unrelated projects.

Use [maintenance](docs/MAINTENANCE.md) for case promotion and project adoption.
